# The Midas Law Book

Static GitHub Pages site for [themidaslawbook.com](https://themidaslawbook.com): a free personal-finance guide landing page, glossary, and a few HTML chapters excerpted from the Guide PDF.

## Pages
- `index.html` — Home (framework, downloads, FAQ)
- `articles/` — Free chapters from the Guide
- `glossary.html` — The guide’s printed glossary
- `about.html`, `contact.html`, `privacy.html`, `terms.html`
- `app/` — Coming-soon notice (the interactive app is not live)

The Guide and Workbook PDFs live in `assets/books/`.

## Run it
```
python -m http.server 8000
```

Then open `http://localhost:8000`.
